新增电影标准流程

只需导入一次统一入口：
https://raw.githubusercontent.com/joyharry-cmd/subtitles/main/shadowrocket/subtitles.module
新增电影后需在 Shadowrocket 更新这个模块，确认脚本下载成功；不必重新添加模块。旧 E.T. 模块仍有效，但请避免和总模块重复启用同一规则。

提供材料：有权使用的 UTF-8 SRT/WebVTT；字幕来源和发布许可证明；电影名称和购买版资源 ID；目标替换语言；实际字幕媒体 m3u8（不是 master）；开头、中段、结尾 WebVTT 样本，含完整 X-TIMESTAMP-MAP；完整请求主机和路径（删除查询参数中的账户、签名、令牌）；已知对白对应播放时间。不要提交 Cookie、Authorization、dsid 或完整抓包。

在 movies/<电影标识>/ 创建目录，复制 examples/movie.json 为 config.json，填写 resource、language、hosts、path_prefix。放入输入字幕、脱敏相对路径播放列表和样本。生成器离线运行，不下载受保护媒体。playlist_origin_local_ms 必须依据样本确认，不能由 MPEGTS 数值猜测；所有样本映射必须一致。跨段提示以完整原始时间重复放入重叠片段，不截断。支持 SRT 逗号毫秒及 WebVTT；当前仅支持连续、同映射、V2-N 文件命名。末尾 discontinuity+empty 可在核实后从输入移除；中间不连续、多映射和非零偏移拒绝生成，需专门适配。

运行 python tools/build.py；执行 python -m unittest discover -s tests 和 node verify.cjs。输出为每部电影 subtitle.js 及 shadowrocket/subtitles.module。先用个人本地文件实测，再根据权利许可审查。输入字幕、样本和生成 JS 默认不应加入公开仓库，除非已明确获准。publish_authorized=true 且 rights_evidence 非空才通过 --publish；这是人工声明检查，不是自动版权鉴定。现有 E.T. 权利状态未确认，--publish 会阻止整库重新发布，不能伪填授权绕过。

提交经授权文件及更新总模块。GitHub Actions 只做验证，不自动上传字幕或推送生成文件。不要直接推送未授权输入；CI 不是隐私隔离区。建议通过 PR 审查文件清单，合并后更新设备总模块。GitHub 更新不是自动推送到设备，需手动刷新模块。

iPhone/iPad：启用脚本和 HTTPS 解密并完全信任证书，停用重复模块，在线重载电影并选配置的目标语言。测试第一句、中段、跨段对白、末句、拖动与重播。当前 E.T. 未经真机测试；抓到的路径变化会停止匹配，应更新配置，不能放宽为整个 Apple 域名。
